A simple breakout to place a TO92 JFET (D - G - S) such as the LSK170 and similar JFETs.

This (tight) design affords TO-92 versions of the LSK170 to be screened internally. This this board is only intended for people who can't source the LSK170 or similar JFETS in the SMD version.
